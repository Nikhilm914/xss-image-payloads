# Responsible Use Policy

This repository contains **intentional** cross-site scripting (XSS) proof-of-concept
payloads. They exist to help defenders and authorized testers understand and remediate
a real, well-documented class of vulnerability.

## Intended use

- Security research and education.
- Bug-bounty testing **within an in-scope program's rules**.
- Penetration tests and red-team engagements **with written authorization**.
- Building and validating detections, filters, WAF rules, and upload sanitizers.

## Not permitted

- Testing against any system you do not own or lack **explicit written permission** to test.
- Any use intended to cause harm, gain unauthorized access, or exfiltrate data.

Unauthorized access to computer systems is illegal in most jurisdictions
(e.g. the US CFAA, the UK Computer Misuse Act). **You are solely responsible for
how you use these files.** By using them you accept that responsibility.

## Reporting

Found an issue with a payload, or want to add one? Open an issue or pull request.
This repo does not ship any live service, so there is no production system to report against.
